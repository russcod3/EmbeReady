# Welcome background

`qwen-flow.webp` is the clean opening frame of the **right-hand Docs card**
from [QwenCloud](https://www.qwencloud.com/), retrieved on November 26, 2026.
It contains none of the numbered labels from the later animation frames.

Source animation: https://cloud.video.taobao.com/vod/gNc9tyd67jyO5dXje8g-Dq4vc4XJDWBLxEVpFRaTKdc.mp4

The welcome page mirrors the artwork to leave space for its own text. Curves
are separate, label-free SVG paths. A lightweight WebGL displacement animates
the original artwork; the local WebP is also the static fallback. Rendering
stops while the page is hidden, when paused, or with reduced motion enabled.
